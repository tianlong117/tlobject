# 联通云收入统计

读取多个月份的云资源业务明细表，按**归属业务单位**和**云类型（资源池）**统计收入，输出到单个Excel文件的一个Sheet中。

## 输入文件要求

工作目录下需要以下文件：

### 1. 月度明细表
文件名格式：`{年份}年{月份}月云资源业务明细表.xlsx`（可自定义模板）

必须包含以下8列：

| 列 | 字段名 | 用途 |
|----|--------|------|
| A | 业务号码 | 用于判断数据行结束 |
| B | 产品名称 | 参考信息 |
| C | 金额 | 备用（当H列为空时用C/1.06计算） |
| D | 资源池 | **云类型**（骨干云池/合营云/云市场等） |
| E | 客户名称 | 参考信息 |
| F | 客户经理 | 参考信息 |
| G | 归属业务单位 | **归属单位** |
| H | 收入(不含税) | 统计的收入数值 |

### 2. 单位顺序文件
默认文件名：`单位.xlsx`，第1列为单位名称列表，决定输出行的排列顺序。

文件中的数据单位如果在顺序列表中没有出现，会追加在最后。

## 执行方式

在工作目录下运行捆绑脚本：

```bash
python <skill_dir>/scripts/process_cloud_revenue.py [选项]
```

### 常用选项

| 选项 | 默认值 | 说明 |
|------|--------|------|
| `--dir <目录>` | 当前目录 | 数据文件所在目录 |
| `--year <年份>` | 2026 | 处理的年份 |
| `--months <范围>` | 1-5 | 月份范围，如 `1-5` 或 `1,3,5` |
| `--unit-file <文件>` | 单位.xlsx | 单位顺序文件 |
| `--output <文件名>` | 自动生成 | 输出文件名 |
| `--pattern <模板>` | `{year}年{month}月云资源业务明细表.xlsx` | 月度文件名模板 |

### 示例

```bash
# 默认：处理当前目录2026年1-5月
python <skill_dir>/scripts/process_cloud_revenue.py

# 指定目录和月份范围
python <skill_dir>/scripts/process_cloud_revenue.py --dir "E:/工作/2026" --months "1-5" --year 2026

# 自定义输出文件名
python <skill_dir>/scripts/process_cloud_revenue.py --months "1-3" --output "Q1云收入汇总.xlsx"

# 只处理某几个月
python <skill_dir>/scripts/process_cloud_revenue.py --months "3,4,5"
```

## 输出格式

输出一个Excel文件，包含**1个Sheet**：

- **行**：归属单位（按单位.xlsx顺序）+ 底部合计行
- **列**：
  - A列：归属单位
  - 每月4列：云类型1 / 云类型2 / ... / 小计
  - 最后4列：合计区（各云类型汇总 / 总计）
- **表头**：两行 —— 第一行月份合并，第二行云类型子标题
- **样式**：蓝色表头、浅蓝合计行、数字千分位两位小数、首行首列冻结

## 注意事项

1. 月度文件如果不存在会跳过并警告，不会中断处理
2. 收入优先读取H列（公式计算结果），H列为空时用C列/1.06计算
3. 1月和2月如果数据完全相同，说明文件可能是重复的，提醒用户核实
4. 单位.xlsx中的单位如果不在数据中则不出现在输出中
5. 需要Python环境安装 `openpyxl` 库（`pip install openpyxl`）
