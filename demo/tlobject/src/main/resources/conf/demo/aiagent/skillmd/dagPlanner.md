---
description: 任务规划技能——将复杂需求分解为子任务并编排为DAG工作流
---

当用户的需求涉及多个步骤、多个 Agent 协作，或需要结构化分解时，
调用此技能生成执行计划。输出包含 MD 文件路径和 DAG 结构（节点+边），
可用于后续的 workflow 执行。

## 参数

- **requirement**（必填）: 完整的需求描述，越详细生成的计划越精准
- **planName**（可选）: 自定义计划名，不指定则根据需求内容自动生成
- **forceRegenerate**（可选）: 设为 true 跳过缓存强制重新生成，默认 false

## 适用场景

- 多步骤任务：需要先 A 再 B 再 C
- 多 Agent 协作：需要不同专长的 Agent 分工合作
- 并行任务：多个独立子任务可同时执行
- 条件分支：根据中间结果决定后续路径

## 输出说明

计划生成后返回：
- MD 文件路径（含完整 DAG 定义）
- 节点数和边数
- 缓存命中状态（exact/semantic/LLM生成）
- 计划描述

生成的 MD 文件可通过 agentWorkflow 模块执行。
