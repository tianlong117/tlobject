# 变更记录

## v1.0.0

首个版本。

### 核心能力

- 支持三种输入：`.mmd` 源码、`.md` 文档（提取 mermaid 代码块，无代码块则自动生成）、纯文本（`--text` 或 `.txt`）。
- 输出格式 `png` / `svg` / `pdf`，PNG 支持 `--scale` 清晰度倍率。
- 4 种内置主题：`default`、`dark`、`forest`、`neutral`。
- 中文节点与中文边标签正常显示。
- 每次渲染同时输出图片与同名 `.mmd` 源码，便于二次编辑。
- 自动生成模式的关键字映射：判定词（判定/是否/判断/校验/检查/条件）→ 菱形；起止词（开始/输入/接收、结束/输出/返回/完成）→ 圆角；其余 → 矩形；分支词（失败/异常/错误/超时/降级）→ 额外分支节点与边标签。
- 判定优先于起止匹配，避免「校验输入」被误判为起点。
- 节点文本超过 20 显示宽度自动折行，中英文按显示宽度加权计算。
- 特殊字符自动转义，防止破坏 Mermaid 语法。
- 附带 `test/run_selftest.py` 环境与端到端自检脚本。
- 附带 `examples/` 三份示例，覆盖三种输入模式。

### 已知限制

- 自动生成仅支持 `flowchart TD` 的线性主链，不支持横向布局 `LR`。
- 不自动生成子图（`subgraph`）。复杂分支、并行流程、多层嵌套请手写 `.mmd` 后渲染。
- 自动生成的节点形状由关键字决定，无法在同一份纯文本里表达循环、汇聚等语义。
- 依赖外部 mmdc 与 Chromium，首次运行可能因下载内核而耗时较长。
- 中文显示依赖系统字体，字体缺失时会渲染成方块。
- 一次仅处理一份输入，批量场景需循环调用。
