# mermaid-flowchart

把一个想法、一段 Markdown 或一份纯文本，直接渲染成可交付的流程图图片。

## 能力清单

- 三种输入自动识别：`.mmd` 源码、`.md` 文档、纯文本（`--text` 或 `.txt`）。
- 输出 PNG / SVG / PDF 三种格式，PNG 支持清晰度倍率调节。
- 中文节点与中文边标签正常显示，不出现方块或问号。
- 无 Mermaid 代码块的 Markdown 也能出图：按标题与列表结构自动推导流程。
- 附带同名 `.mmd` 源码，图片与源码一并留存，方便二次编辑。
- 4 种内置主题，适配浅色、深色、文档、演示等不同场景。

## 三种输入模式

### 一、.mmd 源码模式

直接渲染一份 Mermaid flowchart 源码。

适用场景：流程图需要精确控制形状、分支、子图，或由人工/工具生成好了源码只想出图。
这是保真度最高的模式，脚本不做任何改写。

### 二、.md 文档模式

从 Markdown 中提取 ```mermaid 代码块渲染；若文档里没有代码块，则从标题层级与列表项自动生成流程图。

适用场景：已有设计文档、方案文档、需求文档，希望顺手产出一张流程图。
文档里已写了 mermaid 代码块时，以代码块为准，正文内容被忽略。

### 三、纯文本模式

用 `--text` 直接传一段文本，或指向一个 `.txt` 文件，脚本按关键字规则自动生成流程图。

适用场景：会议纪要、口述流程、临时梳理的步骤清单，只想快速看一张图。
自动化程度最高，但结构由规则推导，复杂逻辑仍建议改写为 `.mmd`。

## 命令行参数

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `--input` / `-i` | 路径 | 无 | 输入文件，支持 `.mmd`、`.md`、`.txt`。与 `--text` 二选一 |
| `--text` | 字符串 | 无 | 直接传入文本，自动生成流程图并渲染。与 `--input` 二选一 |
| `--output` / `-o` | 路径 | 与输入同目录同名 `.png` | 输出文件路径 |
| `--format` | `png` / `svg` / `pdf` | `png` | 输出格式 |
| `--scale` | 整数 | `2` | 渲染清晰度，传给 mmdc 的 `-s`；数值越大图越清晰、文件越大 |
| `--theme` | `default` / `dark` / `forest` / `neutral` | `default` | Mermaid 主题 |
| `--verbose` | 开关 | 关闭 | 打印详细过程，排查问题时可开启 |
| `--help` / `-h` | 开关 | 无 | 显示帮助 |

`--input` 与 `--text` 必须提供且仅提供一个。

## 调用示例

```bash
# 1. 渲染一份现成的 mermaid 源码
python mermaid_render.py --input examples/example_flow.mmd -o flow.png

# 2. 从中文方案文档出图，导出 SVG
python mermaid_render.py --input examples/example_flow.md --format svg

# 3. 纯文本直接出图（中文，用 \n 分隔步骤）
python mermaid_render.py --text "用户提交申请\n校验申请资料\n判断额度是否充足\n审批通过\n返回结果" -o approval.png

# 4. 导出高清晰度 PDF，用于汇报材料
python mermaid_render.py --input examples/example_text.txt --format pdf --scale 3 --theme neutral

# 5. 深色主题加详细日志，方便排查渲染问题
python mermaid_render.py --input examples/example_flow.mmd -o dark.png --theme dark --verbose
```

## 自动生成流程图的规则

纯文本与无代码块的 Markdown 按以下规则推导：

### 节点形状

| 命中的关键字 | 形状 | Mermaid 包裹符号 |
|---|---|---|
| 判定、是否、判断、校验、检查、条件 | 菱形判定 | `{ }` |
| 开始、输入、接收 | 圆角起止 | `( )` |
| 结束、输出、返回、完成 | 圆角起止 | `( )` |
| 其余 | 矩形处理 | `[ ]` |

### 优先级与分支

- **判定优先**：先匹配判定词再匹配起止词。例如「校验输入」含「校验」与「输入」，判为菱形而不是起点，避免流程入口画错。
- **分支词**：失败、异常、错误、超时、降级。命中的行会额外生成一个分支节点与带标签的边，形成侧向出路，而不是串进主链。
- **超长折行**：节点文本超过 20 个显示宽度自动插入换行。中文按 1 个宽度计，英文与半角按 0.5 计，因此中英混排的折行位置符合视觉预期。
- **特殊字符转义**：括号、方括号、花括号、引号、冒号、分号、竖线、反斜杠、井号、百分号、`& * = + ~ ^ $ @ ! ?`、中文标点（，。：；（）【】、）等一律替换为空格并合并连续空白，防止破坏 Mermaid 语法。
- **行类型识别**：`#` 标题、`一、` 中文序号、`1.` 数字序号、`-` `*` `•` 无序列表、`1)` `a)` 括号序号，都会被视为步骤；表格行、分隔线、代码围栏自动跳过。

## 输出产物

每次渲染产出**两样东西**：

1. **图片**：按 `--format` 生成的 `png` / `svg` / `pdf`，路径由 `--output` 决定。
2. **同名 `.mmd` 源码**：与图片放在同一目录、同名、后缀 `.mmd`。
   例如 `-o order.png` 会同时得到 `order.png` 与 `order.mmd`。

保留源码的意义：图形不满意时，可直接编辑 `.mmd` 再渲染，不必回头重写输入文本。

## FAQ

**1. 图里中文变成方块或乱码怎么办？**
本机需安装中文字体 Microsoft YaHei 或 SimHei。Windows 通常自带；精简系统或 Linux 容器需先装字体再重跑。字体缺失时 PNG/PDF 会出现方块，SVG 因依赖查看器字体表现可能正常，但交付前请统一核对。

**2. 提示找不到 mmdc 怎么处理？**
先确认 Node 已安装：`node --version`。再在项目根目录执行 `npm install @mermaid-js/mermaid-cli`，确认生成了 `node_modules`。脚本用 `npx --no-install mmdc` 调用，只认本地安装、不会自动联网下载，所以没装就一定报错。

**3. npx 执行失败或长时间卡住？**
常见原因是首次运行时 mmdc 需要下载 Chromium 内核，网络受限会卡住。可先用 `npx --no-install mmdc --version` 单独验证 mmdc 本身是否可用；若该命令正常，再把问题定位到浏览器内核下载，配置代理或预置内核后重试。

**4. 图太长、节点太密看不清怎么办？**
优先改用 `.mmd` 手写，用 `subgraph` 分组并分行排列。自动生成模式只产出线性主链，步骤过多时无法自动分层。另外可提高 `--scale` 到 3 让细节更清晰，或改 `--format svg` 后在各处无损缩放查看。

**5. Markdown 里没有 mermaid 代码块会怎样？**
不会报错。脚本会退化为自动生成模式，从标题层级和列表项推导流程图；如果正文既无标题也无列表，只有零散句子，则按句子逐条串成链。需要精确结构时请显式写入代码块。

**6. 如何修改主题或提高清晰度？**
主题用 `--theme default|dark|forest|neutral`，清晰度用 `--scale`（默认 2，常用 3），格式用 `--format png|svg|pdf`。三者可组合，例如 `--format svg --scale 3 --theme forest`。

**7. 能否连续渲染多个文件？**
脚本一次处理一份输入。批量场景请用循环调用，或在 `test/run_selftest.py` 基础上改造成批处理脚本。
