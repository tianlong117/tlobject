# 脚本执行 Skill

通过子进程执行预先部署的脚本文件。

## 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `script_path` | string | 是 | 脚本文件名或相对路径（如 `process.py`、`scripts/run.sh`），**不是 shell 命令** |
| `arguments` | string | 否 | 传递给脚本的参数（空格分隔），如 `--months 1-5 --output result.xlsx` |

## 使用场景

- 执行预先部署的数据处理脚本
- 运行报表生成程序
- 调用已有的自动化脚本

## 注意事项

- **script_path 必须是文件名或相对路径，不能是 shell 命令**（如 `dir`、`ls`、`rm` 等系统命令会被拒绝）
- 脚本必须在允许的目录范围内
- 解释器由配置指定（默认 python）
- 超时后进程会被强制终止
- 不同的 skill 实例可配置不同的脚本目录和解释器
- **重要：每个任务只调用一次即可，拿到结果后直接回复用户，不要反复调用**
