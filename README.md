     统一对象消息编程从根本上说不是一个编程或应用框架，而是一个编程思想。传统编程我们都是直接调用对象的方法，消息<br>
   编程是通过给对象发送消息来进行方法的执行，这改变了对象间互动的模式，而使编程 和应用具有了很大的灵活性。具体上<br>
   统一对象消息编程有以下三个特点：<br>
 1、所有对象通过消息进行互动<br>
    如传统当调用一个对象A的方法func，则我们一般是A.func()。通过消息对象，那我们将是：<br>
    msg.action("func")<br>
    putMsg(A,msg)  <br>
 2、所有对象通过名字来互动<br>
    如上我们可以直接给对象实例A发送消息，但是为了更加的灵活和方便，对于每个对象，我们赋予一个名字<br>
    ，该名字为字符串，我们可以简单的通过对象的名字来操作对象。如可以给A对象赋予一个名字“worker”，<br>
    则传递消息的指令如下： <br>
    putMsg("worker",msg)<br>
 3、所有对象的创立（实例化）通过统一的工厂创立，我们可以直接使用对象的名字而无需操心对象的创立、启动<br>
   、初始化 。如上，我们不需要创建worker这个对象，仅仅是直接使用即可：<br>
     putMsg("worker",msg) <br>
